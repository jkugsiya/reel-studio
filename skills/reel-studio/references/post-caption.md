# Post Caption

Write the text that goes under the reel. Offer one recommended caption plus one shorter and one alternative-language
version, each in its own `text` code block so it copies cleanly.

## Structure

1. **Hook line** (first 125 characters show before "more"): the news or the surprise, matching the reel's hook.
2. **What it is:** one or two lines on what was made or shown, in the creator's voice and language mix.
3. **Credit lines** where true: tools used ("Built with Claude Opus 5.5"), collaborators, a bonus in the video.
4. **Call to action** that matches the outro card ("Kaisa laga? Comment karo 👇"), plus one question that invites
   replies ("Next kya banayein?").
5. **Required credits** for licensed media (for example "Photo: Wikimedia Commons, CC BY-SA 4.0").
6. **Hashtags:** 8 to 12, mixing broad (#VR, #AI, #TechReels) and specific (#MetaQuest, #ClaudeAI, #GameDev).

## Rules

- Use the creator's language mix. If they speak Hinglish on camera, write Hinglish in Roman script.
- One emoji per line at most; they mark rhythm, not decoration.
- No claims beyond what the reel shows or the creator said. Remove lines the creator hasn't confirmed.
- Suggest tagging the brands and tools named, and tell the creator to check exact handles; don't guess them.
- Mention adding the product or game name when it exists; it helps search.
